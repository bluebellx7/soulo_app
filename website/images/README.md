# Website product assets

The four `soulo-home*.webp` images are actual Soulo 1.1.4 (build 19) screens captured on an isolated iPhone 17 Pro simulator. No browsing history, accounts, or user data were copied into this simulator.

- `soulo-home-zh.webp` / `soulo-home-en.webp`: Forest gradient, dark appearance, platform group picker enabled.
- `soulo-home-light-zh.webp` / `soulo-home-light-en.webp`: Serenity gradient, light appearance, platform group picker enabled.
- `app-store-qr.svg`: QR code for `https://apps.apple.com/app/id6761165330`, error correction M and a four-module quiet zone. It points directly to the same destination as the download button.

Screenshots are encoded as lossless WebP to reduce transfer size without changing their pixels. The website applies the device frames with CSS. Keep screenshot pixels unmodified and replace each language pair together when the app UI changes.

- `search-home.png`: user-supplied homepage foreground screenshot, copied unchanged from https://www.dkluge.com/images/apps/soulo/search-home.png on 2026-09-05. Used in both website languages; the rear phone still uses the localized light screenshot.
