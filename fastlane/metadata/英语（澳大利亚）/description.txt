Soulo is a multi-search browser for iPhone and iPad. Enter a query once and switch between search, social, video, shopping, knowledge and AI platforms without typing it again.

Find information, read articles, play media and manage downloads in one browser.

• Search your way: Add platforms, organise groups and reorder them. Select text to search in a new Soulo tab.
• Ads and privacy: Filter ads, subscribe to third-party rules and mark unwanted ads yourself. Manage filtering and tracking protection by site. Private browsing does not save history.
• Audio and video: Playback speed, repeat, floating mini-player, Picture in Picture, background playback and AirPlay. Capture video frames, mirror the picture and press and hold for a temporary speed boost.
• Downloads and files: Find images, audio, video and documents on webpages. Save images in batches. Browse files in a list or cover grid, rename them, import from Photos and transfer over Wi-Fi.
• Archives: Extract ZIP, RAR and 7z files. Create ZIP and 7z archives with optional password protection.
• Books and reading: Read TXT, PDF, EPUB and supported DRM-free MOBI, AZW and AZW3 books. Adjust reading fonts, text size, line spacing and backgrounds. Reflowable books support simplified/traditional Chinese display conversion; webpage reading mode extracts articles and lets you continue to the next page.
• Extensions: Import, edit and run JavaScript userscripts, manage site matching and permissions, and install compatible WebExtensions.
• Web tools: Page translation, find in page, full-page screenshots, image text recognition, desktop/mobile modes, custom user agent and site certificate details.
• Bookmarks and sharing: Organise bookmarks in folders and import or export HTML bookmarks used by Chrome, Edge and other browsers. Create webpage QR codes with the site's icon, then share, save or copy them.
• Make it yours: Customise wallpapers, the toolbar and app icon quick actions. Reach common tools through widgets, Shortcuts and URL schemes. Optionally sync settings with iCloud.

Media, ebook and extension availability depends on file formats, website restrictions and system version.
