Soulo は、iPhone および iPad 用の高速でプライベートなマルチ検索ブラウザです。 1 つのクエリを入力すると、再入力することなく 40 以上の検索、ソーシャル、ビデオ、ショッピング、ナレッジ、AI プラットフォームを切り替えることができます。

自分らしくブラウジング
• タブ、ブックマーク、履歴、ダウンロード、カスタマイズ可能な検索プラットフォーム
• プライベート ブラウジング、トラッカー保護、広告ブロック、サイトごとの制御
• モバイルおよびデスクトップ Web サイト モード、ページ ズーム、翻訳、全ページ キャプチャ
• Webページリソースインスペクターを使用して画像、ビデオ、オーディオ、ドキュメントをダウンロード
• Live Text を使用して Web ページ画像からテキストを抽出する

iPhone と iPad 用に構築
• iPad上の複数の独立したウィンドウ
• Soulo にリンクまたはテキストを直接共有します。
• Siri、Shortcuts、Control Center、ロック画面およびアクション ボタンからダウンロードを検索して開きます。
• 実際の進行状況と一時停止/再開を伴うバックグラウンドダウンロード
• ライブ アクティビティと Dynamic Island ステータス

ウェブを拡張する
UserScript または互換性のある WebExtension をインストールし、権限を明確に管理し、組み込みの API ドキュメントを使用して独自のスクリプトを作成します。

iCloud 設定の同期を有効にしない限り、Soulo は閲覧データをローカルに保存します。プライベートブラウジングでは履歴は保存されません。

記事や電子書籍を読み、ファイルを管理し、Wi-Fiで転送できます。
