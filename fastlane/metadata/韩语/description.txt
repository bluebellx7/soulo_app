Soulo는 iPhone과 iPad용 멀티 검색 브라우저입니다. 검색어를 한 번 입력하면 검색, 소셜, 동영상, 쇼핑, 지식, AI 플랫폼을 오가며 검색할 수 있습니다.

정보 찾기, 글 읽기, 미디어 재생, 다운로드 관리를 하나의 브라우저에서 이용하세요.

• 검색: 플랫폼을 추가하고 그룹과 순서를 조정하세요. 선택한 텍스트를 Soulo의 새 탭에서 검색할 수 있습니다.
• 광고와 개인정보 보호: 광고 필터, 타사 규칙 구독, 직접 광고를 지정해 숨기기를 지원합니다. 사이트별 필터와 추적 방지를 관리하며, 개인정보 보호 브라우징은 방문 기록을 저장하지 않습니다.
• 오디오와 동영상: 재생 속도, 반복, 플로팅 미니 플레이어, 화면 속 화면, 백그라운드 재생, AirPlay를 지원합니다. 동영상 프레임 캡처, 좌우 반전, 길게 누르는 동안 임시 배속도 가능합니다.
• 파일: 웹페이지의 이미지, 오디오, 동영상, 문서를 찾고 이미지를 일괄 저장하세요. 목록 또는 표지 격자로 파일을 보고 이름 변경, 사진 가져오기, Wi-Fi 전송을 이용할 수 있습니다.
• 압축: ZIP, RAR, 7z 압축 해제 및 ZIP, 7z 압축 생성을 지원하며 암호 보호를 선택할 수 있습니다.
• 읽기: TXT, PDF, EPUB 및 지원되는 DRM 없는 MOBI, AZW, AZW3 전자책을 읽으세요. 글꼴, 크기, 줄 간격, 배경을 조정할 수 있습니다. 재배치 가능한 전자책은 중국어 간체·번체 표시 전환을 지원합니다. 웹 읽기 모드에서는 본문을 추출하고 다음 페이지를 이어 읽을 수 있습니다.
• 확장 기능: JavaScript 사용자 스크립트를 가져오고 편집·실행하며 적용 사이트와 권한을 관리하세요. 호환되는 WebExtension도 설치할 수 있습니다.
• 웹 도구: 페이지 번역, 페이지 내 찾기, 전체 페이지 스크린샷, 이미지 문자 인식, 데스크탑·모바일 모드, 사용자 지정 사용자 에이전트, 사이트 인증서 확인.
• 북마크: 폴더로 정리하고 Chrome, Edge 등에서 사용하는 HTML 북마크를 가져오거나 내보내세요. 사이트 아이콘이 들어간 페이지 QR 코드를 만들어 공유·저장·복사할 수 있습니다.
• 맞춤 설정: 배경화면, 도구 막대, 앱 아이콘 빠른 동작을 설정하세요. 위젯, 단축어, URL 스킴으로 자주 쓰는 기능에 접근하고, 원하면 iCloud 설정 동기화를 켤 수 있습니다.

미디어, 전자책, 확장 기능의 사용 가능 여부는 파일 형식, 웹사이트 제한 및 시스템 버전에 따라 달라집니다.
