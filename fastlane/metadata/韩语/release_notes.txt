• 지원되는 사이트에서 회차 추출, 역순 정렬, 빠른 전환, 선택한 회차 일괄 다운로드와 실패한 다운로드 재시도를 지원합니다. 길게 누르면 일시적으로 빨라지고 놓으면 원래 속도로 돌아옵니다. 동영상 도구 조작도 더 부드러워졌습니다.
• 다른 도메인으로 자동 이동할 때 확인하는 설정을 추가했습니다(기본값은 꺼짐). 신뢰할 도메인과 새 탭에서 열기를 지원합니다. 광고 오버레이 제거, 뒤로 가기와 하위 메뉴 조작을 개선했습니다.

• 새 기기에서 iCloud 동기화를 켤 때 기존 설정을 덮어쓰는 문제를 수정했습니다. 로컬 설정 백업을 추가하고 공유 링크 처리를 간소화했습니다.

• 설정에서 Soulo를 기본 브라우저로 선택하면 다른 앱의 웹 링크를 바로 열 수 있습니다.
• 웹 페이지 로딩, 광고 필터링 및 페이지 전환 응답성을 개선했습니다.
• 창 크기 변경 시 레이아웃, 배경화면 자르기 및 읽기 환경을 개선했습니다.
