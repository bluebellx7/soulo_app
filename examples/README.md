# Soulo 官方模板

[自定义市场](https://soulo.dkluge.com/custom-market.html) 提供 8 个首页、8 个新标签页和 8 个小组件。`catalog.json` 记录源文件、模块、名称、正式作品 ID 和已上架版本。更新已上架模板时使用原作品 ID，以便设备上的安装记录能识别新版本。

- 首页和新标签页为可编辑的单文件 HTML。搜索与快捷入口调用 Soulo，便笺、计时和待办使用本机存储。
- 小组件为 WidgetKit 使用的 JSON。配置沿用现有市场协议，图标、主入口和中号快捷入口由 Soulo 渲染。
- 发布前使用市场校验器及 Soulo 渲染测试检查源文件、预览与交互。预览不使用个人书签和搜索记录。

布局参考了极简新标签页的主次分配、内容型工作台的快捷入口和壁纸上的对比度处理。[Bonjourr 项目](https://bonjourr.fr/) · [Jason Pepping 的新标签页设计](https://dribbble.com/shots/3568037-Browser-new-tab-dashboard) · [Manganum 设计案例](https://www.jdavydko.com/case-studies/manganum.html)
