## 进度

- 阶段 1–5 已实现；阅读追加了无固定容器、延迟正文、同源嵌入、目录误判、隐藏文本与预格式小说的回归样例，并完成电子书式排版、字体、进度和已载入章节。
- 阶段 6 已通过公开 UIKit API 配置标准编辑菜单；模拟器原生复制可用，查询/翻译动作保留。菜单的最终方向和动作组合仍由 iOS 决定，真机竖排菜单需复测。
- 原生 UI 已通过页面信息展开、UA 编辑入口、资源七类切换、阅读入口/章节、文件导入与 Wi-Fi 入口、收藏/历史顺序和外观同行检查；截图检查修复了信息展开挤压和阅读页背景不一致。
- ABP 核实：内置自有语法子集解析器，使用 EasyList 等订阅；没有官方 Adblock Plus 完整引擎，详见测试指南。
- 阶段 7 已完成：完整 XCTest 297 项通过，Release 真机目标编译通过（未签名）；逐项手动测试已补入 [PHASE_6_12_TEST_GUIDE.md](PHASE_6_12_TEST_GUIDE.md)。
- 用户旧小说网址本轮返回 HTTP 403；通用样例已用于验证，不将该网址记为通过。
