Soulo 1.2.15（55）本轮修改清单

此清单汇总 1.2.15 计划及后续补充需求。含新增功能、已有功能优化和问题修复；不把旧版已有功能重复称为新增。

首页、新标签页与收藏
1. 调整首页搜索框位置、收藏距离、最近搜索的上方间距与左对齐；去除搜索框阴影，保留适当透明度。
2. 隐藏或清空标题、副标题时，保持搜索框的位置稳定；编辑标题、副标题可恢复默认。
3. 默认副标题统一为英文 Search anytime, anywhere.；保留用户自定义内容与主动留空的选择。
4. 新标签页整体位置调整，包括最后补充的再次上移；图标、标题、搜索框与快捷链接一同移动。
5. 新标签页移除“快速链接”标题，调整品牌图标大小、快捷链接图标及文字长度。
6. 快捷链接优先显示标记爱心的收藏，无爱心时回退到收藏前几项；空列表显示操作说明。
7. 收藏支持重命名、爱心标记与筛选；快捷链接标记显示在收藏网址旁。
8. 收藏与新标签页快捷链接共用拖拽排序；文件夹保持在前，长按提供管理菜单。
9. 清除全部收藏需要输入确认文字；取消不删除，主动删除与同步删除状态分别处理。
10. 浏览器工具栏新增“新标签页”；iPad 首页工具栏可容纳更多入口，并限制宽度。
11. 改进网站图标获取、缓存与缺失占位；关闭最后一个标签后回首页。
12. 改进大量标签滚动与截图管理；分组可以折叠，减少无用渲染。

平台、批量导入与同步
13. 自动隐藏平台栏改为用户主动点击网页内容后触发，保留动画和提示。
14. 平台管理及首页搜索图标菜单均可控制自动隐藏平台栏。
15. 平台排序支持跨组拖拽。
16. 批量导入 JSON 支持具名分组和同时导入多个组；优化编辑区、示例和底部导入按钮布局。
17. 提供平台 AI Prompt 说明与复制；可以复制全部平台链接、导出当前分组 JSON，交给 AI 整理。
18. 重新导入支持默认追加，以及明确确认后的覆盖替换；覆盖前保存备份，先校验完整数据。
19. 完善收藏、平台和设置的 iCloud 合并与删除状态处理，保留两端内容及稳定标识；避免空数据覆盖有效数据。

视频播放与选集
20. 新增网页播放器自动接管开关，默认关闭；视频工具中的主动播放、全屏操作始终使用用户选择的播放器。
21. 移除网页视频带网址的中间预览页，直接进入竖屏或横屏全屏；本地文件及音频保留其适用流程。
22. 优化 iPad 窗口内横竖屏切换，窗口不能旋转时采用播放器画布旋转，避免系统方向错误提示。
23. 全屏加载、错误提示改为覆盖视频画面，不挤动进度和按钮；时间与进度条稍微下移。
24. 未知时长时不显示虚假的 100% 进度；补充加载、失败、重试状态。
25. 选集支持按最长文字自适应列宽；纯数字可显示更多列，长标题设上限。
26. 点击集数立即关闭面板，直接在视频中央加载；失败时重新显示错误与重试。
27. 改进通用选集识别、MSE 播放器真实源识别及切源后列表状态，保留当前播放上下文。
28. 修复 MTYY 页面网页能播、工具全屏不能播以及下载失败：保留网页来源策略、复用短时效播放列表，并处理确认有效的图片头 TS 分片。
29. 修复部分播放器下拉菜单文字与背景不匹配，补足空来源名称，避免切源后面板错误关闭。
30. 完善 FastStream 与视频工具的衔接，使用其当前选中的真实媒体源；扩展播放器与网页接管开关各自独立。
31. 完善浮窗、全屏退出、直链媒体打开和错误分类，避免正常退出全屏时误报无法播放。

脚本、扩展及安装
32. 完善公共 WebExtension 兼容层、用户脚本接口、消息、执行环境、网络请求、文件及 Blob 下载等能力。
33. 使用真实扩展包验证 FastStream、猫抓、TYTY 与篡改猴等重点流程；兼容能力依据扩展具体 API 和站点行为。
34. 扩展界面继续由 WebView 渲染，完善国际化、CSS/资源加载、弹窗尺寸、安全区和移动端表单适配。
35. 改进 FastStream 进度拖动、刷新与标签切换、启动提示、下载保存反馈及下载后文件入口。
36. 完善猫抓复制、播放、保存、下载目录及高级媒体处理相关衔接，减少触摸时误出现粘贴菜单。
37. 扩展商店链接、扩展自有页面按合适的新标签流程打开，保留原网页与返回路径，避免扩展页遮挡平台和商店导航。
38. 修复脚本与扩展文件、文件夹选择入口，优化扩展列表信息布局。
39. 安装条可收起、展开和移动；安装流程支持取消，完成后提供成功提示及已安装状态，权限可在管理页调整。
40. 脚本与扩展增加长按删除及管理入口；移除区域文字提取内置示例。
41. 更新开发文档及复制给 AI 的脚本 Prompt。

下载、存储空间、广告与隐私
42. 改进下载速度及 HLS 进度统计，使用真实接收字节；避免预分配 BT 文件被误认为已完整下载。
43. 完善 HLS 鉴权、Cookie、来源策略、AES 密钥、暂停恢复、离线导出与错误页校验，数据写磁盘，避免整片视频堆积在内存。
44. 完善 BT Tracker 动态更新、DHT、连接与调度；实际速度仍受种源及网络影响。
45. 存储空间区分安装后的程序大小与应用数据总量，解释阅读数据等分类，避免同一文件重复计数。
46. 显示网站及 IndexedDB 等网站数据用量和清理入口；保留不能精确归属时的估算说明。
47. 下载文件、收藏壁纸、阅读数据、过滤规则、设置备份、脚本与扩展等可进入对应管理页；统一行对齐与箭头位置。
48. 可直接清理的项目集中排列；应用数据增加批量清理，默认勾选可重建缓存，保存内容需主动选择与确认。
49. 收藏壁纸取消收藏或删除文件后，重新统计对应占用；安全清理保护正在使用的文件与下载任务。
50. 规则缓存改用兼容旧格式的无损压缩，减少重复表示和过期编译缓存；保留用户现有订阅选择。
51. 新安装默认减少重叠规则源，未启用的规则源不下载。测试归档约从 149 MB 降到 11 MB，实际占用视规则数量而定。
52. 修复 iOS 16 多层广告规则管理入口不能打开或卡顿，统一广告过滤图标与文字对齐。
53. 补充第一方广告容器的过滤；检查 MTYY 底部广告未命中纯网络规则的原因，并验证白名单可绕过过滤。
54. 完善外部 App 跳转与跨域跳转处理，包括哔哩哔哩番剧相关页面；增加退出清除浏览记录开关，默认关闭。
55. 优化设置备份恢复：减少重复设置通知，规则处理移出主线程，先关闭确认弹窗再执行；说明其为配置备份。
56. 修复 iOS 16 早期系统浮层被扩展成整页留白的问题，改为贴近按钮、按内容高度显示。

系统能力、图标、设置与网站
57. 适配原生分层图标：默认纯白背景、放大并保留品牌轮廓的矢量 Logo，调整笔触与尾部，适配深色、透明和色调外观。
58. 增加 iPad 多窗口与菜单操作，窗口间移动标签保留网页与导航状态。
59. 按系统、设备及语言能力适配设备端 SpeechAnalyzer 语音输入、Foundation Models 网页摘要、Siri/快捷指令、后台媒体合并导出与系统字幕能力，并保留旧系统回退。
60. 整理相关设置名称及入口，单独呈现网页背景延伸相关选项，完善辅助功能、低动态与低透明度显示。
61. Telegram 反馈入口提供独立页面，可打开 https://t.me/soulobrowser 的外部 App。
62. 官网新增适合手机使用的 Soulo 扩展页面，区分 Chrome/Edge 商店，提供官方链接及 Soulo 内安装入口。
63. 扩展推荐复用现有反馈接口，链接、推荐理由可选填；列表卡片进一步压缩高度。
64. 导航移除“在线工具”但保留页脚入口；movies.html 增加 souju.ai，resources.html 网盘类在前、磁力种子类在后。
65. 主 App、小组件与分享扩展统一为 1.2.15（55）；维护 50 个语言的文案与生成 JSON，并运行严格本地化和一致性检查。

验证范围
本轮最终阶段使用 iPhone、iPad 和 iOS 16 模拟器，未操作真机。当前本机 SDK 为 26.2；先前 SDK 27 与真机证据见既有 QA 报告，不代表本轮改动已在 iOS 27.2.1 真机完整复测。
MTYY 两集在两种解码器中解码、全屏切集及真实分片下载已通过；下载验证使用两段真实分片并导出可播放 MP4，没有下载整部影片。
实际 iCloud 服务传输与所有未来扩展、网站不能由模拟器和有限样本保证；同步合并、删除及保存管线已做本地验证。
FastStream 通过用户安装的扩展提供，播放器仍保留 VLC 解码支持。
未提交、推送或上传代码。
