# Soulo 使用说明

## 搜索与标签页

首页可以输入关键词或完整网址。搜索后切换上方平台，即可用同一关键词查看不同平台的结果；需要登录的平台仍由该平台处理账号和权限。

收藏和历史位于资料库。浏览器的标签管理页用于切换、关闭和恢复标签；恢复关闭标签会恢复原页面，是否保留网页内的临时状态取决于网站与可用内存。无痕会话不会写入普通标签恢复记录。

多标签页的分组视图按网站自动归类，可为现有网站组重命名或置顶；分组成员仍由网站地址决定。它不创建任意的手动标签组。首页的平台分组单独用于组织搜索平台。

外接键盘支持 Command-L 编辑地址、Command-T 新建标签、Command-W 关闭标签、Command-Shift-T 恢复标签、Command-R 刷新和 Command-F 查找文字。iPad 上还可用 Command-N 打开独立窗口；各窗口分别管理标签，会共用设置与资料库。

自定义搜索平台时，搜索地址中的 `%@` 表示编码后的关键词。优先使用网站本身提供的搜索链接，不要把登录令牌或私人地址放入共享配置。官网的[搜索源目录](https://soulo.dkluge.com/sources.html)提供可导入的模板；外部平台的可用性、登录要求和地区限制可能变化。

## 广告过滤与网站兼容

广告过滤包括网络规则、页面隐藏规则和手动标记。页面功能异常时，可以在当前网站的站点面板检查广告过滤、跟踪保护和浏览器标识，随后重新加载。站点开关只调整对应站点，关闭全局过滤会影响所有网页。站点可选择长期放行或临时放行；临时放行在重启 Soulo 后失效，长期设置继续保留。

网站加载失败并不一定代表网址无效。可以使用重试或兼容模式；保留准确网址、操作步骤及过滤开关状态，有助于排查。

## 播放、下载与文件

网页、下载与文件中的媒体使用共用播放会话。视频设置可选择默认 Soulo 或系统播放器，并设置长按倍速、网页视频工具与选集按钮；媒体编码、投屏与画中画支持取决于解码器、设备和源网站。

普通视频切换到其他 App 时会暂停；主动开启的画中画或 AirPlay 会话可以继续。本地音频可以后台播放。文件中的音频会使用同目录的音频列表，播放到结尾后可继续下一首。睡眠定时可选择时长或“播放完当前项目”，到时暂停；切换播放器不会重新计时。系统音量、音频权限及播放源失效也可能影响后台播放。

网页中的媒体可以通过播放菜单或下载入口创建任务。下载后的文件可在资料库打开、播放或分享。下载列表支持按名称或来源网址搜索，组合下载状态与文件类型筛选，再按时间、名称或大小排序。“进行中”包含正在下载和已暂停的任务。下载任务的删除与清除已完成记录是不同操作：删除文件前应阅读确认提示，避免把需要保留的文件一并移除。

文件列表可在当前文件夹内按名称搜索，按文件类型筛选，并按时间、名称或大小排序，文件夹默认排在前面。文件管理支持文件夹和压缩包操作。移动或重命名文件时，先等待相关下载完成；同名目标与无效名称会提示处理。重要文件建议先导出一份。

Wi-Fi 传输要求设备位于同一局域网，并保持传输页面打开。按页面说明开启传输，必要时打开配对码；本地网络权限、路由器隔离或网络变化可能导致连接失效。

在资料库顶部点标题打开菜单，可进入“阅读列表”。阅读模式中的文章可存入阅读列表，离线打开已保存的文字并保留阅读位置。阅读列表只保存已加载的正文，不会下载图片、链接页面或尚未加载的章节。最多保存 500 篇，单篇正文上限 2 MB，正文合计上限 20 MB；达到限制后需要先删除不再需要的文章。

## 数据同步、备份与清除

**iCloud 设置同步**用于外观、首页、浏览、隐私、壁纸偏好、平台配置与站点规则。它不传输搜索历史、收藏、网页缓存、Cookie、网站登录状态和下载文件。使用相同 Apple 账户也不会因此自动出现另一台设备的这些内容。

**设置备份**是设备上的设置快照，可在“设置备份”页面保存、恢复、删除，以及通过 JSON 文件导入导出。导入只把备份加入列表，不会立即改变当前设置；选择“恢复”才会应用。恢复会替换快照所包含的设置；它不是下载文件、收藏或整台设备的备份。迁移前的初始副本会保留，普通副本按保留数量滚动清理。备份格式版本与 App 的商店版本号是不同概念。

**收藏导入导出**使用书签 HTML 文件，适合在浏览器之间转移收藏；导出后请自行保存文件。平台配置导出则只包含搜索模板与对应配置，不能替代收藏备份。

**清除缓存**与**删除个人数据**是不同操作。网站 Cookie 和网站数据被删除后可能退出登录；历史、收藏、下载、文件和备份应分别在对应入口管理。收藏壁纸、下载文件和阅读记录属于保存内容，不能当作临时缓存删除。任何清除操作都应以界面列出的范围为准。

## 个性化与快捷操作

设置顶部可按页面名称搜索，例如“视频”“壁纸”“备份”；匹配页面可直接进入，外观和首页开关等同页项目按分区显示。

首页壁纸可选择本地效果或在线来源；在线图片需要网络，切换来源后会加载该来源的候选图片。来源不可用时可先选择本地背景，不必重置全部设置。

“长按快捷操作”是指长按 iOS 主屏幕上的 **Soulo App 图标**，不是长按首页内容。设置中可选择扫描、清除缓存、新建隐私标签和搜索等操作。

浏览器与首页工具栏可以分别自定义。隐藏工具栏后，页面菜单仍提供返回工具栏和站点面板等入口。功能说明以当前版本设置页面为准。
