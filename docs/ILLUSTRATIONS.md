# Soulo 插画素材

使用内置 image_gen 生成，参考 HeartCalm 的手绘线条与安静留白；未修改 HeartCalm。透明 PNG 随 App 离线打包。浅色保留淡紫与暖白，深色以去饱和反色呈现，插画对辅助功能隐藏，不响应触摸。

| 素材 | 使用位置 |
| --- | --- |
| `IllustrationFiles` | 搜索历史、下载和文件列表空状态 |
| `IllustrationBooks` | 收藏与书库空状态 |
| `IllustrationTransfer` | Wi-Fi 传输未开启时；开启后让位给二维码 |

文件位于 `Soulo/Assets.xcassets/Illustration*.imageset/illustration.png`，仅在相关工具页使用。
