# 网页广告手动标记

## 行为

- 入口：地址栏锁/网站信息图标 → 标记广告；也可从同一弹窗中的“广告过滤”详情进入。网页工具最顶部保留广告过滤入口；标记广告及站点保护从锁面板进入。
- 点选区域后显示高亮；支持沿父级扩大、回到较小选区、预览、取消。点击链接或跨域 iframe 时用于选择，不执行链接跳转。
- 原生操作区确认“隐藏并记住”才保存。默认按当前主机与网址路径匹配；不保存或匹配查询参数、片段。可切换为当前主机的整个网站，规则不扩展到其他子域名。
- 保存后提供即时恢复；广告过滤中的“已标记广告”按网站列出规则、路径和日期，可逐项恢复。手动规则与订阅分开，更新或重置订阅不覆盖手动标记。
- 遵循广告拦截总开关、网站白名单及现有登录/验证兼容策略；暂停拦截会恢复手动隐藏区域。预览不计入统计，确认保存才增加近似隐藏计数。
- 明确保存的规则保留在本机，包括用户主动在隐私标签内保存的规则；不自动同步、不上传规则或页面内容。持久化内容仅为主机、可选路径、选择器、ID 和时间。
- 避免整页、正文容器、登录表单和大面积容器被选中。跨域框架只支持整体隐藏；不能通过点选移除视频流内部的插播内容。网站更改布局或选择器后可能需要重新标记。

## 实现与性能

- 在专用 WKContentWorld 中运行；只有原生保存按钮写入规则，网页脚本无法调用同名桥接。消息检查主框架、所属 WebView、会话令牌和网址，导航/切换标签后取消旧会话。
- 使用构造样式表，以支持禁止内联 style 的 CSP 页面；普通动态节点由 CSS 自动匹配。针对 inline `display: ... !important` 的覆盖，记录并恢复原始声明，只检查新增子树或变动目标，按批处理，不定时扫描整页。
- 没有匹配规则的页面不启动 DOM 观察器；取消选择后移除遮罩、预览样式与选择事件监听器。规则恢复时不刷新网页，不修改既有自动拦截规则。
- 更新注入脚本时保留其他脚本及其 content world，不重新编译网络订阅规则。
- 新文案沿用 ReadingTools 的简体中文、繁体中文、英文表及现有英文回退；未变更版本、Build 或商店元数据。

- 等待网站信息弹窗消失后再打开详情或开始标记，不再使用固定 0.16 秒延迟。
- 交互验证时捕获既有广告规则编译在 `WebCore::initializeTagNameStrings` 崩溃；将 WebKit 原生调用限定到主 actor，通过回调桥接返回结果，规则 JSON 准备仍在后台。Apple 将 [WKContentRuleListStore](https://developer.apple.com/documentation/webkit/wkcontentruleliststore) 标为主 actor API。

## 后续界面与工具整合

- 锁面板的“标记广告”和“隐私设置”同排，标记按钮显示当前主机保存的规则数量。两个保护详情入口为灰色，浅色模式的卡片背景使用 60% 不透明度。
- 网页工具中的广告过滤固定排在顶部，媒体倍速图标使用随明暗主题变化的中性色。
- 阅读模式作为扩展中心列表末尾的内置开关；开启后在网页“脚本命令”中出现阅读模式入口，关闭后隐藏入口。
- 多标签页的省略号直接打开锚定小弹窗，包含顶部标签栏开关、两种布局示意及关闭操作。设置持久化，单标签始终隐藏顶部标签栏。
- 首页菜单与标签卡片普通长按操作使用中性色图标；关闭全部标签及单个标签的关闭操作使用破坏性红色。桌面模式统一使用空心显示器图标。

- 剪贴板提示展示文本摘要，最多取 240 字符并折叠空白、截断加省略号；实际搜索仍使用完整内容。首次读取遵循 iOS 粘贴授权，拒绝时保留原来的点击读取提示。
