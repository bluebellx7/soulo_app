## 选词搜索加载修复

- 用户反馈新标签创建后网页空白。早期 UI 用例主要检查标签数量和地址栏，未充分确认正文加载，不能据此判定完整搜索成功。
- 已复现两个独立问题：搜索页出现时恢复旧分组会覆盖目标引擎；导航栈重建与新标签创建同时发生，会让旧视图拆掉刚挂载的新 WebView。
- 选词搜索保留已经准备好的引擎和请求；通过展示绑定收起资料库和阅读器，保持导航控制器本身不变，然后在视图任务中创建标签，加载前设置对应内容模式。这也避免了系统选词菜单退出时重建导航控制器触发的 UIKit 导航栏断言。
- 新增 `SelectionSearchNavigationTests`，验证实际结果正文、中文与特殊字符、已有网页的选词入口、新 WebView 挂载及来源页面状态保留。
- `/tmp/soulo-selection-stable-root.xcresult`：上述两项回归通过；`/tmp/soulo-selection-stable-page-ui.xcresult`：真实长按选词菜单、新标签数量及百度搜索结果正文验证通过，截图已人工检查。
