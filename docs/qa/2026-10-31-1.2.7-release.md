# 1.2.7 版本与商店 JSON

用户要求解决已批准的 1.2.6 不再接受新构建的问题，将版本改为 1.2.7 并更新 JSON。

- 在工程配置源 `project.yml` 中将主 App、小组件和分享扩展的 `MARKETING_VERSION` 同步为 1.2.7，运行 `xcodegen generate` 重新生成工程。
- `xcodebuild -showBuildSettings` 分别确认 `Soulo`、`SouloWidgetExtension` 和 `SouloShareExtension` 的 Release 设置均为 1.2.7。工程原有 `CURRENT_PROJECT_VERSION` 51 保留；上传时的构建号管理继续沿用原有流程。
- 核查全部 50 个商店语言目录的六类字段，共 300 份源文件。保留用户已有名称、副标题、推广文本、描述、关键词及新增内容正文，只将 50 份新增内容首行的版本标识统一改为 1.2.7。
- 使用 `python3 scripts/export_metadata_json.py` 重新生成 JSON，`app.version` 为 1.2.7，50 种语言齐全；全部新增内容均使用 1.2.7 标识。生成文件没有手工修改。
- `python3 scripts/export_metadata_json.py --check` 通过。
- `python3 scripts/check_localization.py --strict` 通过：890 键 × 50 种语言。
- 全部商店字段均在字符上限内，导出器没有报告需人工处理的不可见字符警告。
- `fastlane/README.md` 的当前版本说明同步更新。版本提交同时包含已有的商店文案源文件与重新生成的 JSON，确保仓库源数据和 JSON 一致。

读取构建设置时，Xcode 在 JSON 后输出已有 PLzmaSDK PrivacyInfo.xcprivacy 资源提示；已单独解析设置 JSON，三个目标的版本均已确认。此检查没有生成或上传新归档；实际提交需重新 Archive，旧归档仍携带旧版本号。
