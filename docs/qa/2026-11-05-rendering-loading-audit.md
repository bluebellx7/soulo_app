# 渲染与加载检查：2026-11-05

本轮在保留工作区已有修改的基础上，检查启动、首页输入、网页首屏、加载期间交互、标签预览、资料库、网站图标、文件缩略图、壁纸与后台定时器。生产代码仅调整广告脚本缓存和规则筛选；未调整导航、页面显示时机或播放器行为。

## 已确认的问题与修改

1. 完整广告隐藏脚本和原生过滤配套脚本共用 `cosmeticScript.json`，启动预热、规则就绪及页面挂载会请求不同版本，两者不断覆盖。现在分别保存到 `cosmeticScript.json` 和 `nativeCosmeticScript.json`，沿用精确输入键、损坏回退、原子写入与失效校验。目录最多保留三个固定文件（含原生规则标识缓存），不会随启动次数累积。
2. 每条选择器反复通过字符串 API 执行相同的正则匹配。现在复用编译后的 `NSRegularExpression`，保留原有表达式、大小写选项和完整 UTF-16 匹配范围。新增保护根元素、边界、中文、emoji 和大小写混合浮层的回归。
3. 新增仅在 DEBUG 且显式启用 `SOULO_BROWSER_TRACE=1` 时输出的脚本阶段时间点，便于区分规则解码、选择器筛选、JSON 生成和缓存命中。

## 其他检查结论

- 首页连续输入不会逐字符发布整个浏览器状态；输入、组合输入保护和尺寸变化下的焦点检查通过。
- 5000 条历史数据下，单次历史写入中位数约 2 毫秒；本轮未调整历史行为。
- 1000 次下载进度更新仍合并为一次写盘；不以减少状态通知为由跳过暂停、完成等状态变化。
- 文件扫描、下载文件大小统计和缩略图生成已有后台路径，未改动。实际视频缩略图生成检查通过，尺寸不超过 420 像素，原文件保持完整。
- 网站图标的并发请求合并、内存/磁盘复用、失败缓存和取消检查通过。
- 64 标签页、多种屏幕尺寸和语言下，仅按需解码预览，预览不会启动各标签的 WebKit。横竖屏截图已查看。
- 大壁纸仍按显示尺寸解码，测试图解码内存由原始 96 MB 限制到 24 MB；缓存恢复不会覆盖用户刚切换的来源。
- 视频工具定时器在空闲、暂停或不可见时为零，活动播放时为一个。

## 验证与结果位置

所有文件位于 `/tmp/soulo-performance-audit-20261105/`。

- `Baseline.xcresult`：40 项基线检查通过（含 WebView 池与输入布局检查）。
- `Regression.xcresult`：70 项单元检查通过，涵盖广告过滤、跨域播放器白名单、验证资源、受保护根元素、缓存失效、输入、资源管理和标签预览生命周期。
- `Interaction.xcresult`：网站图标与视频缩略图共 12 项通过、1 项在线站点用例按开关跳过；界面回归 6 项通过、1 项失败。失败项实际已打开标签面板，但旧用例查找不存在的 `tabs.tab_new_tab`，不是页面点击无响应。修正辅助方法，使用现有 `tabs.done` 返回网页，不修改产品行为。
- `SlowInteraction.xcresult`：修正定位后，该慢加载用例通过，覆盖连续开关菜单、面板外部点击收起、标签面板开关、保留页面重挂载、点击链接、返回及回首页。
- 最终合计：82 项单元检查通过、1 项跳过；7 个不同界面用例均已通过。界面覆盖深浅色首屏、后续导航保留旧页、首页/地址搜索、加载中滚动点击、网页文本输入、资料库各页滑动和点击切换。
- `regression-attachments/`、`interaction-attachments/`、`slow-interaction-attachments/`：截图。已查看中文竖屏及英文横屏标签分组、深浅色首屏、资源未加载完成但内容已可交互的网页截图。
- `startup-baseline/`、`startup-after/`：各八次原始日志、逐次指标及汇总。
- `cache-native-diagnostic/`、`native-miss-after/`：原生脚本未命中诊断；只清除专用模拟器的一份可再生脚本缓存，并保留备份。

这些结果证明本地受控路径有改善，不能代替真机 Release 性能和真实网站网络耗时。尚未据此确认此前用户手机上“首页显示后所有点击都失效”的偶发问题已经彻底消失。
