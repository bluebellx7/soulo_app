# 视频工具与导航回归

视频功能集成在播放器上的紧凑纯图标工具栏，保留无障碍名称。只有识别到剧集时才显示选集图标，主页面与 iframe 播放器均同步更新。展开、收起复用图标节点；工具栏自身的 DOM 变化不触发整页广告或隐私扫描，模糊背景不再进行宽度动画。位置与可见性未变化时不重复写入样式，收起状态收到选集更新时不触发布局。详情页已发现选集但没有可见播放器时，显示可拖动、吸附侧边的“选集”按钮；播放器出现后移除这个备用入口。选集支持线路切换、倒序、上一集/下一集、多选和批量下载，不提供搜索框。长按正在播放的视频临时使用 2 倍速，松开、取消、切后台等情况恢复原倍速。

播放器父容器隐藏或透明时，工具栏同步隐藏，并恢复备用选集入口；开放式 Shadow DOM 播放器也遵守这条规则，避免重复入口。滚动引起的位置更新合并到动画帧。结构化剧集数据异步更新、移除时重新读取，清除失效缓存后回退到 DOM 列表，不需要重载整页。Bilibili 已知视频 ID 不匹配时丢弃旧页面数据；导航切换后也丢弃之前异步检查的结果。刷新合并触发，工具栏操作不触发剧集重扫。

长列表倒序后重新定位到当前集。下载状态按 URL 建立索引，避免每个单元格重复遍历整份队列；列表动态变化时清理已失效的勾选。失败详情提供“重试”，仅重新排入失败集数；批量入队、停止排队合并发布界面更新，重复排入不会产生重复的活动任务。历史清理保留任务顺序，避免旧结果覆盖正在重试的状态。长按提示也不触发整页广告或隐私扫描，松开后的点击屏蔽只作用于原播放区域。

## 导航原则

- 实际请求由 `WKNavigationDelegate` / `WKUIDelegate` 决定放行、取消或等待确认。没有重写整页 HTML，也没有替换网站的链接或点击处理。
- 隔离环境中的点击监听只记录可信事件的来源、链接、表单及结果卡片信息。搜索卡片通过网站自身处理器生成的真实请求继续由 WebView 处理。
- 地址栏、平台入口、真实链接、结果卡片、表单及已批准请求的 HTTP 重定向保留主动访问意图。后台点击引起的无关弹窗和伪造点击仍受广告跳转策略限制。
- “跨域跳转确认”位于“广告过滤”，独立开关，默认关闭；只询问网页自动发起的跨域导航。
- “允许自动跳转”开关、旧偏好读取和对应通用拦截分支已移除。可信点击记录继续用于广告点击识别和跨域确认。
- “外部 App 跳转提示”位于“广告过滤”，默认开启；开启时等待用户确认或取消，关闭后直接尝试打开目标 App，失败仍显示提示。普通链接、脚本按钮、隐藏 iframe 和内嵌登录弹窗使用同一规则；外部 App 链接不被网页广告导航启发式提前吞掉。
- 外部 App 提示只由请求所属的活动标签页处理。提示不再四秒后自动消失；用户选择、离开网页或切换标签页时关闭。
- 百度视频分享页使用的 `https://boxer.baidu.com/scheme?scheme=…` 中转会提取原始 `baiduboxapp://` 链接并走 App 提示流程，不作为普通跨站脚本导航拦截。匹配限定 HTTPS、完整主机、路径和目标 scheme，编码参数保持原样；不对百度域名整体放行。
- “跳转白名单”默认提供 44 个常用域名，可增删和恢复默认。`*.qq.com` 匹配主域名及子域名，`qq.com` 只匹配该域名；不匹配 `notqq.com` 或 `qq.com.evil.example`。白名单仅跳过目标域名的确认，不关闭广告过滤。
- 确认条包含取消、继续、新标签打开和信任域名并继续。按钮整块背景可点击，高度至少 44pt；信任操作使用黄色。新标签入口不因请求类型隐藏：普通 GET 保留原请求上下文，表单或流式请求在新标签按目标地址发起 GET，不重放原请求体；“继续”仍放行原请求。新标签操作保留当前页；标签满 20 个时显示已有的数量上限提示，保留当前确认以便重试。

## 自动检查

在专用 `Soulo Default Browser QA 20261008` 模拟器上运行相关 XCTest / XCUITest；页内查找使用 `Soulo Find QA 20261016`。设置弹层打开后，界面测试须等待目标控件出现再点击，避免把转场期间未送达的点击误判为导航失败。重点覆盖：

- `BrowserAdNavigationTests`：链接与脚本卡片、无关弹窗、iframe 点击劫持、伪造点击。
- `ExternalNavigationServiceTests` / `ExternalWebLinkUITests`：提示默认值、旧偏好兼容、持久化与同步刷新、设置即时切换、直接打开地图 App、重复确认、普通与新窗口链接、脚本底部按钮、隐藏 iframe 和内嵌登录弹窗。
- `WebDomainNavigationTests`：默认关闭、域名边界、通配符、增删持久化、失效按钮和导航取消。
- `WebEpisodeTests`：通用 DOM、MacCMS、Bilibili 分 P/合集、Youku 页面数据、结构化数据动态更新与清除、透明播放器与备用入口。
- `WebEpisodeDownloadTests`：真实 MP4 字节、登录 cookie、嵌套播放器、并发去重、部分失败、停止排队与重试。
- `WebAdOverlayCleanupTests`：芒果 TV 的“继续使用浏览器”、ReactModal 和兄弟节点残留遮罩、正常登录与服务协议保护、关闭广告过滤时的 Cookie 遮罩清理，以及工具栏变化不触发整页扫描。
- `WebEpisodeAndAdNavigationUITests`：网站原有点击处理、重定向、表单、确认条、新标签、白名单管理、纯图标工具栏重复展开不新增节点、选集动态显示和隐藏、选集倒序与批量下载、吸附拖动、长按倍速恢复。
- `BrowserToolbarResponsivenessUITests`：底部返回使用同一个 WKWebView 历史，并保留交互响应；“打开网页”“网页工具”“脚本命令”保留系统下拉菜单，覆盖反复展开、跨页面能力刷新保持打开、关闭和执行缩放操作，以及地址栏键盘收起后的交互。未观察到键盘弹出时，不因单独的收起通知重建菜单锚点。Mac 的 iPhone 镜像鼠标输入仍需真机复核。
- 页内查找：由 `WKWebView.find` 选中匹配，隔离脚本统计可访问文档中的文字，并把已有选区滚动到可见区域，避开键盘；不依赖网站的 `window.find`，不替换页面文字节点。脚本无法统计跨域 frame 的匹配总数时显示“—”，仍保留原生结果切换。输入合并处理，关闭、切换标签或导航时取消旧查询，防止旧回调恢复过期状态。`TabManagerTests` 覆盖匹配、前后切换、循环、特殊字符、隐藏文字、无结果和取消；`BrowserToolbarResponsivenessUITests` 覆盖真实菜单入口、键盘、匹配位置、关闭、反复打开以及查找后再使用下拉菜单。工具操作在弹层消失后执行，键盘收起后等到下一次打开菜单再更新锚点。
- `python3 scripts/check_localization.py --strict`。

## 实站检查范围

已从用户提供的片吧详情页获取实际 HTML，并用 WKWebView 验证选集提取。芒果 TV 已使用实际页面在 WKWebView 中复现：自动隐私处理把服务协议内容隐藏，留下 ReactModal 遮罩。修复后保留完整、可操作的服务协议提示，由用户自己选择；不会自动接受或拒绝协议。已过滤的 Cookie 提示和广告则按实际 modal 关联清理遮罩、滚动锁定与无障碍隐藏状态；芒果 TV 的兄弟节点遮罩也有覆盖。

当前环境请求百度移动搜索会返回安全验证页；Bilibili 返回 412，Youku 返回挑战页。因此这三类站点目前通过本地结构与交互样例回归，仍需在正常登录或可访问的真机环境补充实站检查。受加密或访问权限限制的资源不会因选集提取而自动变得可下载；批量下载只保存实际解析出的媒体资源。

## 大量标签与查找焦点

不再限制标签总数，新建标签、首页搜索、选中文字搜索和跨域确认中的新标签入口遵守同一规则。只保留最近少量网页运行，下载中的页面继续受到保护；内存警告释放后台网页和预览，不删除标签。会话一次发布恢复结果，预览在卡片可见时异步读取；连续标签操作合并保存，应用切后台立即保存。

顶部标签条使用惰性布局，概览最多创建附近 7 张卡片；滑动和快速定位滑条只浏览预览，点选时才激活网页。超过 99 个标签显示 99+，无障碍名称仍报告实际数量。`TabManagerTests` 覆盖 500 个标签的身份、地址、活动位置、保存恢复、无额外 WebKit 实例和关闭行为；`BrowserToolbarResponsivenessUITests.testManyTabsUseBoundedPreviewsAndScrubberWithoutLoadingUntilSelection` 覆盖 26 个标签和快速定位后点选页面。

查找输入框使用原生 UITextField，在加入窗口、原生菜单完成关闭后获取焦点，并验证焦点没有被菜单恢复过程夺走。输入法组合期间不改写输入内容，也不发起查找。`TabOverviewLifecycleTests` 覆盖窗口后挂载、自动聚焦、重新聚焦和预览图按需读取；界面测试通过当前第一响应者输入文字，不先用测试框架激活字段。
