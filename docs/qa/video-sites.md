# 视频嗅探、播放与下载实测

测试日期：2026-09-25。环境：iPhone 17 Pro 模拟器，iOS 26.2，使用 `SouloTests/WebViewScriptsTests.swift` 的实时网页检查。测试结果只对应下列公开样本和当时网站响应；网站页面、权限和视频分发方式可能变化。

| 网站 | 嗅探 | 播放验证 | 下载验证 |
| --- | --- | --- | --- |
| 哔哩哔哩 | 找到真实媒体资源；过滤了混入播放器数据的统计、个人资料链接 | 下载后用 AVFoundation 确认有 1 条视频轨、1 条音频轨 | 样本完整下载，2,175,078 字节；同一 CDN 地址在另一次测试返回 404 |
| YouTube | 识别到 SABR 播放资源 | 下载后用 AVFoundation 确认有 1 条视频轨、1 条音频轨 | 样本经分段下载和音视频合并，生成 29,901,412 字节 MP4 |
| 抖音 | 找到直连视频资源，HEAD 返回 200 | 下载后用 AVFoundation 确认有 1 条视频轨、1 条音频轨 | 样本完整下载，15,785,310 字节 |

另使用 Apple 公开 HLS 测试流验证了网页嗅探及 AVPlayer 输出视频帧。使用本地 MP4 测试文件验证了直连下载的完整流程。HLS 离线下载依赖系统后台下载服务；该服务在本次模拟器环境中报 XPC 不可用，因此尚未完成真机 HLS 下载验证。

复测公开样本：在模拟器的 `launchctl` 环境设置 `SOULO_LIVE_MEDIA_QA=1`，运行 `SouloTests/WebViewScriptsTests/testLiveVideoSiteInspectionMatrix`。可选 `SOULO_QA_SITE` 限定网站（如 `MangoTV`），`SOULO_QA_PLAY_SITE` 验证 HLS 画面，`SOULO_QA_DOWNLOAD_SITE` 完整下载直连资源。网站样本 URL 见测试文件。实时测试会发起真实网络请求，且网站可能拒绝自动化客户端。

## 本轮复测：2026-09-25

本轮改为所有网站都记录页面发起的 Fetch/XHR 媒体请求；直连预览不再强制按 MP4 解码；资源下载与 HLS 离线任务使用网页实际的 User-Agent。模拟器定向测试还覆盖了 HLS 任务创建前的暂停、恢复和取消。

| 样本 | 本轮观察 |
| --- | --- |
| Apple 公开 HLS | 嗅探到清单并在 AVPlayer 输出视频帧 |
| 本地 H.264/AAC MP4 | 直连下载完成，文件含视频轨 |
| 哔哩哔哩 | 找到 1 个 MP4 地址，但这次 CDN 返回 404；未验证本轮下载 |
| 芒果 TV | 找到 1 个 HLS 清单；清单及首个分片返回 200，AVPlayer 输出 960 × 540 视频帧 |
| 爱奇艺 | 找到 1 个 HLS 清单，清单返回 200；分片使用 HTTP，原生请求受 ATS 拦截。相同分片改用 HTTPS 的 HEAD 请求返回 200，但 App 尚未改写清单地址 |
| YouTube、抖音 | 本轮样本在 WKWebView 中加载为空白，未取得媒体资源；之前成功的下载记录仍只对应当时样本 |
| 优酷、腾讯视频 | 页面主要引导打开 App 或小程序，未暴露可用媒体地址 |

本轮没有完成真机 HLS 离线下载验证，也不能据此承诺上述网站的视频均可下载。带登录权限、短期签名、分段传输或 DRM 的资源需要分别验证；过期 CDN 地址不能作为下载能力回归的证据。
