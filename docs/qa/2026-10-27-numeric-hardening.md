# 网页数值与下载进度防闪退加固

基线为 `8f23630`。本轮仅本地修改，不改变版本号或商店文案，不提交、push、上传或发行。

## 已实现

- **统一外部数值解析：** `SafeNumericValue` 仅接受可表示的非负整数，拒绝 NaN、无穷大、超范围、小数和布尔值；保留 Int64 最大整数的精度，支持原有整数形式的字符串。
- **广告及隐私计数：** 单次网页上报限定为 1–1,000,000；超出范围直接忽略，不限幅后冒充真实计数。服务层亦校验单次增量。历史累计值不清空，累计和界面汇总使用防溢出加法，溢出时停留在 Int.max，不发生环绕或崩溃。普通统计、站点归一和隐私模式不记录的行为保持。
- **空白页探针：** 每个计数字段都必须是有效的非负整数。遇到非法字段直接停止本次恢复判断，不将异常值当作零而错误重载网页。
- **分轨及 SABR 下载：** 进度回调与完成路径的总长统一进行溢出检查。缺失、负数或不能安全求和的预期总长按未知处理，不伪造 0 字节总文件或错误百分比；正常长度恢复后继续显示正常进度。已接收字节异常求和防止环绕。
- **下载管理展示：** 总长变为未知时清除旧百分比，之后可恢复正常进度；状态、文件、暂停/继续和完成判定不变。
- **prompt 预防性处理：** 确认动作改为弱捕获所属 UIAlertController，打断代码中的潜在强引用环。没有把该改动称为已测量或复现的内存泄漏修复。

## 定向覆盖

新增 15 个测试方法，覆盖：

- 正常整数及 Int64.max 的数字/字符串精度；NaN、Infinity、超范围、小数、负数、Bool、NSNull 和缺失输入。
- 单次网页计数上限，已有极大历史计数的增量、汇总与保存/读取，不清空正常历史。
- 分轨进度的实际产品 URLSession 委托回调：两个合法但合计溢出的长度变为未知，随后正常回调恢复正确进度。测试任务不发起真实网络请求。
- 完整生产 WKWebView 消息路径：本地网页连续发送超大广告/隐私计数，再发送正常计数，异常被忽略、正常计数仍准确。
- 生产空白页探针：本地网页覆盖 body.children.length 为 1e100，等待延迟探针执行后文档实例保持、没有闪退或误重载。
- 进度由已知转未知再恢复的状态。

## 验证与原始失败

- 首轮未签名模拟器扩大回归：229 项中 224 通过、3 失败、2 原有实站检查跳过。3 个失败均为既有后台下载用例，会话日志包含无法创建后台任务/远端 session 不可用及等待超时，原结果包 `regression.xcresult` 保留。
- 不改产品代码或测试断言，使用本地 ad-hoc 签名模拟器宿主后，同一 3 个用例全部通过，结果包 `background-signed.xcresult`。未通过修改超时或跳过用例掩盖首轮失败。
- 最终相同范围的签名模拟器回归通过：229 项中 227 通过、2 项原有实站检查跳过、0 失败。包含全部 15 项新增测试和先前 3 项失败用例，专项与重复运行不累加计数。结果包 `final-signed-regression.xcresult`。
- 未签名设备 Release 构建通过，实际最低系统版本 17.0、SDK 26.2；不是签名 Archive 或发行 IPA。
- 严格本地化 877 键 × 50 语言、商店生成 JSON 的 50 语言 `--check` 及 diff 空白检查通过。没有更改工程版本或商店内容。

本轮只使用独立 iPhone 15 Pro Max / iOS 26.2 QA 模拟器。没有 iOS 17.0 原机验收，也没有重新执行屏幕键盘 Search 的 XCUITest；该入口的上一轮结果不冒充本轮的新界面验收。

## 明确保留的两项下载生命周期待办

以下不在本轮四类数值修复的完成范围内，不因数值测试通过而标为已修复：

1. 页面 blob/data 下载桥和传输状态仍与 Coordinator 的拆装相关。跨标签继续下载需要稳定 owner、回挂和关闭时收尾的独立实现及回归；本轮没有用“切标签即取消下载”代替修复。
2. HLS 系统后台事件 completion 与异步导出完成时机仍需协调，并覆盖后台执行期限、持久化和重启恢复。本轮未以简单延迟回调冒充完整后台恢复。
