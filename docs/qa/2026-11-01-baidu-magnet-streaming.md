# 百度扩展、磁力链接与边播边下复查

## 范围和变更

- 百度规则仍为独立、可查看的内置用户脚本，版本更新为 2.1.0，默认开启。保留用户明确关闭的偏好及其云备份。
- 普通 HTTP 结果和没有提供直链的 HTTP 跳转链接使用浏览器默认激活；不再经扩展消息重新发起原生请求。仅在需要处理 App 唤起或结果提供明确目标地址时使用原有隔离桥接。
- 不增加滚动监听、定时器、MutationObserver、全页结果扫描、后台请求或媒体修改。未改动 WebKit 侧滑、历史恢复、视频工具及下载引擎的产品代码。
- 修复链接测试类的 `hash` 字段与 NSObject 属性重名导致的测试编译失败；将 MP4 测试改为直接使用产品的 `MediaSession`，移除测试专用播放器缓冲和 seek 回调设置。
- 所有 50 种语言的描述、新增内容、推广文本与关键词更新 BT 边播边下、MKV 和 ed2k/thunder 信息。逐项核对全部六个商店字段，名称和副标题保持现有准确定位。版本保持 1.2.7（51）。生成 JSON 未手改。

## 磁力与播放验证

本轮共通过 28 项不同的 iOS 原生测试；默认值与播放器测试在变更后定向重跑。

- v1 十六进制与大小写 Base32 哈希一致；v2 btmh 和混合磁力解析通过；无哈希、截断哈希和无效/过大种子拒绝。
- 真实 libtorrent 本机对等节点传输：磁力仅获取元数据时不下载内容；选择文件后只下载指定内容；暂停恢复自动重新连接；引擎重建后由 resume 数据恢复；后台暂停与立即恢复的时序、校验中保留已有进度通过。
- 真实种子分片经校验后才能交给播放器；头部、尾部及 seek 优先级通过，排除文件不下载，路径及符号链接越界拒绝。
- `MediaSession` 从未完成的真实种子流起播，时间推进超过 0.6 秒时下载尚未完成；通过产品 `seek(6)` 后继续推进超过 6.2 秒。没有测试专用 AVPlayer 配置或 seek 后补播回调。
- HTTP 流支持 HEAD、单段 Range、尾部 Range、等待缺失数据、416 和不可猜测的资源路径。
- MKV 本地实际解码通过；额外测试 MKV 经相同 HTTP 流接口起播并从 4 秒处继续播放，视频尺寸和时间推进正常。

支持能力不等于任意资源都可下载：磁力需要在线节点提供元数据和分片；没有来源或被网络限制时仍可能无进度。媒体还受编码及分片可用性限制。不能把百分比 0% 单独当作节点数为零。ED2K 是独立协议，本轮未修改其引擎或恢复用户真实任务。
