# 2026-11-07 输入与帮助中心修复

## 反馈与修复范围

- 下载/文件共用的搜索行移除 List 额外的上下内边距，与收藏页的原生搜索行对齐；保持正常字号和至少 44 pt 的操作区域。
- 在每个应用窗口统一安装一次空白点击收键盘手势，覆盖原生页面及同窗口弹层；保留输入框切换、文本编辑、原生控件和 WKWebView 交互。搜索框清空按钮保留输入焦点。
- 触摸开始时记录原输入框，在按钮点击动作处理后再收起该输入框的键盘，避免 iPad 弹层随键盘重排而丢失导航点击；切换焦点时不收起新输入框。
- 首页和历史页移除重复的全局 resignFirstResponder 手势，复用统一处理。搜索框的焦点保护使用弱引用，不持有已移除页面，且不能穿过其它页面或弹层保护相同屏幕坐标。
- 移除收藏菜单中的“仅显示重复项”、对应计算和全部 50 个语言表中的废弃条目；收藏导入去重保持原有行为。
- 帮助中心移除嵌套 NavigationStack 和重复的“完成”，由设置导航或首页工具栏弹层拥有导航和关闭操作。

## 修复前复现

在 iPhone 17 / iOS 26.2 模拟器中通过实际点击复现：

- 从设置搜索进入帮助中心时无法显示欢迎内容。
- 从首页工具栏进入帮助中心时出现两个“完成”。

复现结果：`/tmp/soulo-input-help-20261107/HelpBeforeFixedHarness.xcresult`。

## 验收内容

- 下载与收藏搜索行实际 Cell 高度一致，正常字号和点击区域保留。
- 下载、收藏、设置、新建下载弹层和首页输入后，空白点击收起键盘；输入值保留，重新点击可以继续输入。
- 清空搜索保持焦点，下载地址和文件名可相互切换输入，新建下载可取消返回。
- 收藏菜单不再提供“仅显示重复项”，保留阅读列表、文件夹、选择及导入导出入口。
- 设置与首页工具栏均可进入帮助中心，设置入口可返回，首页入口只显示一个“完成”且能关闭。
- 网页输入及地址栏收键盘后的工具栏响应回归。
