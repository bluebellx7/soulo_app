## 实现边界与结果记录

- 下载/文件共用内存查询，不在搜索输入时扫描磁盘；按状态、类型及名称/时间/大小筛选排序，删除始终映射可见记录身份。
- 设置搜索给子页面显示直接入口；首页等根设置保留可编辑控件。浏览器工具栏提供四种草稿预设，点保存后生效。
- 收藏支持查找、批量删除，导入时跳过同文件夹中完全相同 URL 的记录；跨文件夹收藏保持独立。“仅显示重复项”已根据后续反馈移除，见同日输入与帮助中心回归记录。
- 标签查找包含标题、完整 URL 和关键词；命名/置顶针对已有的按网站自动分组，不将其描述成任意手动分组。
- 阅读列表保存已加载正文，不抓取图片或后续页面。actor 串行持久化，正文每篇 2 MiB、总计 20 MiB，最多 500 篇。文件页提供最近本地媒体/书籍继续入口。
- 播放器共享睡眠定时；本地音频原有后台播放和目录队列保持。后台视频、PiP/AirPlay 的边界沿用已有设置。
- 临时广告例外只在本次进程中生效，不写永久白名单/备份；单站清理使用当前标签的数据仓库并说明同域影响。
- JSON 设置备份导入只新增快照，不自动应用；导出与同步不包含收藏、历史、登录和下载。收藏迁移仍使用 HTML。
- 收藏壁纸是用户数据；空收藏不能开启仅收藏模式。原图迁至 Application Support，清缓存不删除原图或收藏索引。
- 50 语阅读工具与新增 UI 表均完整打包；机器辅助译文已做占位符、品牌、快捷键和重点语境检查，母语润色仍可继续进行。
