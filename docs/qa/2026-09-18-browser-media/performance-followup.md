# 下载提示与多标签性能回归（2026-09-18）

本轮针对视频下载无反馈、切回标签刷新/持续加载提示，以及网页脚本开销进行调整。保留已有 1.1.8 版本和商店文案。

## 调整

- 视频工具发起 HTTP / HLS 下载后立即显示下载状态，成功后复用全局完成提示（通常 4 秒，VoiceOver 为 8 秒），可点击进入下载列表；同一标签中的同一媒体下载进行中重复点击不再重复创建任务。失败继续使用原有错误提示。媒体下载与原生网页下载的计数合并，并受到标签内存回收保护。
- 最近页面保留上限由 3 调整为按设备内存选择 5 或 8（至少 4 GiB 时为 8）；超过上限或收到内存告警仍回收较旧页面，保留现有快照和媒体检查点机制。并非所有 20 个标签常驻，也不承诺系统回收后无需重载。
- 温存标签重新挂载只重接代理和消息处理，不清空/重装脚本及已编译过滤器。用户脚本桥接标识和广告配置签名保存在标签模型内，避免切回时重复执行昂贵的安装工作。
- 重新挂载时立即读取 WebKit 当前进度、加载、标题、历史状态，修复后台已经加载完成、界面却还显示“加载中”的状态遗漏。
- 主文档内容可绘制时取消初次等待提示，后续慢脚本或图片仍按实际状态加载。隔离内容世界的通知带同一 WebView/主帧校验；布局检查使用动画帧或“解析完成且适用样式表就绪”的信号；解析器被慢脚本阻塞时继续保留等待提示，不使用时间兜底提前展示空白正文。
- 广告规则匹配按配置和完整 URL 缓存 CSS 与选择器分组；纯文本更新不再触发整页广告扫描，新增元素及相关样式变化仍进行检查。手工规则的备用扫描同样跳过纯文字更新。
