# 首页按压与加载动效

## 首页

- 统一 `HomePressButtonStyle`：按压缩至 94%，约 70ms 收缩、220ms 弹回；只做绘制变换，保持控件占位。
- 覆盖标题、副标题、标签页、菜单、分组、收藏、最近搜索、快捷入口、剪贴板提示及首页搜索工具和建议操作。
- 搜索栏聚焦时单次缩至 97.5% 后恢复，使用 SwiftUI 关键帧。原生输入框保持原样，键盘输入与文本选择不增加触摸识别器。
- 最近搜索使用按钮反馈，长按删除具有优先级，防止长按释放后误触搜索。删除按钮继续位于右侧，收藏保留原生长按菜单。
- 系统“减弱动态效果”开启时关闭缩放。

## 网页首次加载

- Logo 从 1.5 秒一圈改为 0.8 秒一圈。
- 容器由 76pt 缩到 64pt，笔触由 128pt 缩到 108pt；减淡高光，提示文字使用普通字重和次要颜色。
- 删除独立流光旋转与呼吸缩放，保留一个匀速旋转动画。后台、离开界面或减弱动态效果时停止动画。
- 页面首屏内容判定与 loading 显隐逻辑沿用原实现。
