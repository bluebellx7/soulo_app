# 收藏和历史使用新标签：2026-11-06

## 问题与修改

首页资料库原本直接调用 `performSearch`，没有为所选记录准备独立标签；浏览器内资料库则把选中值交给当前页的地址栏回调或 `webViewModel.loadURL`。因此，从标签面板的加号返回首页后选择收藏，或从浏览器内选择历史，都可能覆盖已有标签。

现在统一由 `LibraryView` 调用 `SearchViewModel.openLibrarySelection`：

- 当前标签已有页面、待加载请求或挂起页面时，创建并选中一个新标签。
- 当前标签确实为空白时直接复用，避免用户已经新建空白标签后又多开一页。
- 保留当前搜索分组，支持收藏网址、访问历史和关键词历史。
- 保留现有的导航返回时序，捕获所属窗口的模型后再打开记录。
- 发送显式导航请求，让已挂载的浏览器也能加载记录；连续打开相同记录仍会产生新的请求。
- 移除浏览器资料库复用地址栏回调的路径。普通地址栏搜索继续在当前标签导航。

修改仅涉及上述路由与对应回归，没有调整版本号或商店文案，也没有提交或推送。
