# 影视导航卡片图标背景

参考用户给出的微度导航截图，在现有紧凑卡片的站点图标后叠加同一张本地 PNG 的模糊背景。默认轻微显示，鼠标悬停或键盘聚焦时展开；深色模式降低背景强度，整体沿用冷白、墨色和灰紫主题。

模糊层不接收指针事件，效果限制在卡片内部。网站标题和外链图标在交互时使用主题色，缺少图片的入口继续显示文字标记。沿用原有卡片高度、导航、分类和收藏交互。

验证：

- `python3 scripts/check_website.py` 通过，目录及结构化数据仍为 90 个网站。
- 原有完整浏览器检查通过：90 个影视入口、85 个搜索源；搜索、分类、收藏、复制降级、5 种宽度统一导航、无 JavaScript、禁止存储。
- 新效果检查通过：背景与前景使用相同图标；浅色、深色悬停状态正常；卡片高度保持；390px 无横向溢出；键盘聚焦显示卡片轮廓；减少动态效果设置下无过渡动画。
- 桌面、手机及局部浅色/深色截图已查看；调整后模糊背景不会溢出至相邻卡片和页面背景。
