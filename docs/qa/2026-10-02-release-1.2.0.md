# Soulo 1.2.0 发布检查（2026-10-02）

版本：1.2.0，构建号：27。主 App、Widget 和 Share Extension 同步修改，以 `project.yml` 为源重新运行 `xcodegen generate`。

## 商店文案与本地化

- 维护全部 50 个语言目录的六个字段：名称、副标题、推广文本、描述、新增内容、关键词。
- 推广文本、描述中的版本推广段落及新增内容已更新，包含页面响应、边播边下、后台下载、全屏与方向恢复、广告点击拦截、剪贴板保护及可确定进度的操作。
- 名称、副标题和关键词经检查后保留，继续沿用现有品牌及有效搜索词。
- 通过 `python3 scripts/export_metadata_json.py` 从源文件生成 JSON；`app.version` 为 `1.2.0`，50 个语言的新增内容均标明 `1.2.0`。
- `python3 scripts/export_metadata_json.py --check`：50 个语言通过，字段长度及源文件一致性检查通过，无零宽字符等导出警告。
- `python3 scripts/check_localization.py --strict`：865 个键 × 50 个语言通过。
- `git diff --check` 通过；相关 Python 脚本语法检查通过。

四个原有按环境启用的用例未运行：

- `testLiveHLSInspectionAndVideoFrames`、`testLiveVideoSiteInspectionMatrix`：需要 `SOULO_LIVE_MEDIA_QA=1`，访问公开流和实际视频网站。
- `testLocalDirectVideoDownloadProducesFile`：需要 `SOULO_QA_DIRECT_URL`。
- `testLocalHLSDownloadProducesPlayableOfflineVideo`：需要 `SOULO_QA_LOCAL_HLS_PORT` 及对应设备测试环境。

本地 MP4、普通 HLS 和 AES-128 HLS 固定数据的下载、播放、导出路径有通过记录。上述环境用例的跳过不作为通过统计。

```sh
xcodegen generate
python3 scripts/export_metadata_json.py
python3 scripts/export_metadata_json.py --check
python3 scripts/check_localization.py --strict

xcodebuild test -project Soulo.xcodeproj -scheme Soulo \
  -destination 'platform=iOS Simulator,id=FE8ED7B2-0818-46A7-AC9C-051B058C7148' \
  -derivedDataPath /tmp/soulo-webview-warmup-derived \
  -disableAutomaticPackageResolution \
  -only-testing:SouloTests \
  -only-testing:SouloUITests/BrowserToolbarResponsivenessUITests \
  -only-testing:SouloUITests/BackgroundDownloadUITests \
  -only-testing:SouloUITests/DownloadPlaybackUITests \
  -only-testing:SouloUITests/VideoFullscreenOrientationUITests \
  -only-testing:SouloUITests/WebPageProtectionUITests \
  -parallel-testing-enabled NO -test-timeouts-enabled YES \
  -default-test-execution-time-allowance 90 \
  -resultBundlePath /tmp/soulo-release-120-20261002.xcresult

xcodebuild build -project Soulo.xcodeproj -scheme Soulo \
  -configuration Release -destination 'generic/platform=iOS' \
  -derivedDataPath /tmp/soulo-webview-warmup-derived \
  -disableAutomaticPackageResolution CODE_SIGNING_ALLOWED=NO
```

模拟器测试及设备架构编译不能覆盖所有真机、系统版本、网站变化或系统长时间调度后台下载的情况。
