# 资料库分页与边缘返回

## 行为

- 收藏、历史、下载、文件四页支持左右分页，点击顶部 tab 也会滚动到对应页面。首次从历史、下载或文件入口进入时，内容与选中 tab 对齐。
- 高亮背景的位置和宽度、图标与文字颜色随实际滚动比例连续变化；中途取消滑动后回到原位。点击切换遵循系统“减弱动态效果”偏好。
- 左侧边缘右滑由导航控制器的原生返回手势处理；普通右滑切换上一页。短距离边缘手势取消时保持当前页。
- 原有条目左滑操作仍可使用。通过条目区域协调手势优先级，不替换系统滚动代理，也不依赖 SwiftUI 私有视图类名。
- 四页保留各自状态，切换后收藏夹仍停留在之前打开的文件夹。只有当前页提供工具栏；文件扫描、下载文件大小统计和播放器导航不会因后台页常驻而额外触发。

## 实现要点

- 使用 SwiftUI 原生分页滚动，并以一致的 `LibrarySection` 标识定位页面；首次显示和宽度变化时重新对齐当前页。
- 高亮直接读取 UIKit `contentOffset`，兼容右到左布局。偏移、视口和内容尺寸的观察按主线程更新合并；离开时取消观察。
- 高亮根据四个 tab 的实际边界插值，因此不同语言的标题宽度及文字放大不需要缩小字号。
- 原有 `SearchHistoryView.swift` 中的其他未提交修改不包含在本次提交内。工程通过既有 XcodeGen 流程重新生成，未改版本、构建号和商店文案。
