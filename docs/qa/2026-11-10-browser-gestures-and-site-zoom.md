# 网页手势、网站缩放与摇晃方向

## 行为

- 设置 → 网页手势：双指手势默认关闭。开启后右滑默认关闭标签页，左滑默认打开标签管理；两侧可独立选择动作或快捷菜单，菜单至少保留一项。
- 同页的「无法后退时」单独控制左侧边缘的单指右滑。默认显示关闭标签页提示；有 WebKit 返回记录时，识别器关闭，交给原生返回。双指总开关不影响这一项。
- 默认达到距离后松手执行，也可选择点按执行。未达距离、回滑、系统取消均不执行。点按模式下，新的网页触摸会收起提示并正常传给网页；结束手势延迟送达的旧触点不会误关提示。
- 滑动过程中只显示图标与操作名称，宽度随文字收紧，使用半透明毛玻璃。右滑靠左、左滑靠右，位于手指上方并保留 24pt 间距；双指取较高触点，避免提示被手指遮挡。只保留 12pt 的侧边弹性位移。切换标签、改变网址、离开前台后清除提示。
- 关闭标签时在图标处播放 280ms 的局部粒子效果，再关闭对应标签。减少动态效果时跳过粒子动画。触摸位移由提示自己的 ObservableObject 更新，不让整棵网页视图随每个触摸采样失效。
- 设置内提供矢量插画和操作预览。预览中的按钮只收起预览。
- 网页手势设置将插画和说明独立分区，分区间距统一为 24pt；开关与左右动作同组，当前动作以第二行显示，右侧预览按钮保留 44pt 点击范围。无法后退时的动作独立分组；执行方式、反馈和菜单沿用设置图标及文字对齐。新增本地化的「预览反馈」，不再与手势预览混用文案。
- 双指识别只接受两个触点同向平移；明显捏合、旋转、纵向移动、第三个触点和短距离滑动不能执行操作。VoiceOver 开启、标记广告和网页视频原生全屏时不触发。
- 双指开始移动允许第二指追上；方向锁定前可在另一指保持按下时重新放置一指。识别后容忍细小的速度、间距和角度偏差，不再沿用起步阶段的严格阈值。方向锁定后按原方向投影计算距离，回滑越过起点也不会错误地重新蓄满。先抬起一指时保留提示和最后的双指位置，全部松开才判断执行；不再于抬指瞬间重新读取、分类已结束的触点。系统取消或明显捏合、纵移仍取消。
- 同页新增「执行反馈」：震动默认开启、声音默认关闭，可分别设置并预览。达到执行距离时提供选择震动；实际执行有效动作时提供完成震动及可选短音效，取消不播放完成反馈。音效为本地生成的 120ms、约 10KB WAV，使用系统 UI 声音 API，不改变网页音频会话。两项偏好加入备份和同步。
- 缩放按完整域名保存，忽略协议、路径、查询和端口；子域名互相独立。新标签、恢复标签、重定向和历史导航恢复对应域名的比例。范围为 50%–200%，步长 10%，100% 删除覆盖值。
- 设置 → 页面缩放：开关、逐站调整、删除、全部恢复。无痕标签可读取已有偏好，但新的调整只留在该标签内存中。
- 设置 → 摇动操作 → 方向：默认左右，也可选上下或任意方向。按屏幕横竖方向选择 Core Motion 轴，明显偏离所选轴的运动清除候选峰值，低幅度的零点经过不打断同一次摇晃。
- 四档力度整体下调：连续峰值阈值为 0.28 / 0.42 / 0.60 / 0.80g，强峰阈值为 0.75 / 1.00 / 1.35 / 1.65g。标准档采用原轻档阈值，保留方向过滤、峰值间隔和冷却时间。
- 上述偏好加入现有设置备份与同步范围；补齐 50 个语言目录。按后续要求将 App 与扩展版本统一设为 1.2.11，审核全部 50 语言、300 项商店字段，更新全部语言的推广文本、描述段落和新增内容，保留仍准确的名称、副标题和关键词；通过导出器生成 JSON，版本一致。未引入第三方依赖或收费服务。

## 原生边缘手势的自动化限制

当前 iOS 26.2 模拟器上的合成单指边缘返回会出现交互取消，关闭新增手势时也能复现。此前的[浏览器状态验收](2026-11-01-browser-state-performance.md)已记录原生边缘注入未验证。本次不重发或强制完成 WebKit 历史导航；实际历史列表用于验证新提示的启停，已有返回按钮用于核对历史导航。

严格的原生边缘诊断仍保留在 `testNativeHistoryWithTwoFingerGesturesDisabled` 中，可通过 `TEST_RUNNER_SOULO_NATIVE_EDGE_QA=1` 单独运行。普通验收跳过这一诊断，不以它代替新增手势的真实多点触摸、确认及取消检查。测试触摸注入使用的 XCTest 运行时接口仅位于 UI 测试目标中，产品代码全部使用公开 API。临时手势日志和外层导航实验代码已移除。

## 标签分组视图的空白退出
