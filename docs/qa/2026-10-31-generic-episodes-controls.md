# 通用资源选集与浮动按钮尺寸

## 修改

- 资源选集改为识别重复的集名与播放地址结构，支持普通列表、表格、重复行、`集名$地址` 文本、textarea，以及 `#` 分集、`$$$` 分线路格式。原有站点类名只作为补充线索。
- 保留云播放页、分享播放页、M3U8 / MP4 直链、隐藏线路、特别篇和签名参数。过滤导航、推荐、广告、报错和复制按钮；拒绝不安全协议、带凭据 URL，以及文字地址与实际链接指向不同媒体的条目。播放器清晰度数组不作为选集。
- 选集浮动入口、视频工具入口及展开后的操作按钮统一为 48×48 屏幕点，图标 23 点。共用缩放计算，补偿无移动端 viewport 的桌面布局、双指缩放及 App 的网页缩放；嵌入式播放器通过原生桥接接收主页面实际比例。重排时将按钮保持在可视区域内。
