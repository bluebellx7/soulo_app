# 选集下载、文件大小和标签分组换行

## 行为

- 选集页右上角增加下载入口，在同一导航栈打开下载列表，返回后仍保留选集页。
- 长按单集可选择下载，不切换当前网页；使用既有选集解析、下载队列及去重逻辑。多选状态保持原有批量操作。
- 下载列表同时展示准备中的选集，避免刚触发下载时出现空列表；已保存下载显示文件大小，未知总量的进行中任务也显示已接收字节数。
- 文件列表和网格均显示大小。普通文件读取文件字节数，HLS 引用读取其真正的离线媒体包，不把小型 JSON 引用当成视频大小。
- 媒体包统计在后台执行，按下载完成列表更新，逐项支持取消并跳过符号链接，不在进度变化或行布局中反复遍历文件。
- 标签分组改成组内纵向网格，普通手机每行三个；窄屏和辅助功能大字号减少列数。每组自动换行，页面统一纵向滚动，底栏固定。保留最近使用顺序、分组顺序、选择及关闭动作。
- 保留本轮返回误显示加载失败的修复，以及此前键盘、设置行对齐和选集恢复修复。未修改版本或商店文案。
