按钮使用独立浏览器上下文、移动 UA 与真实点击验证；原生确认页使用真实 WKWebView、产品 Coordinator、下载和 SwiftUI 安装页验证。确认前已安装脚本数量保持不变，未将外部脚本安装到用户手机。原始证据为 `source-buttons.json` 及 `NativeAudit.xcresult` 中四条 `LIVE_SCRIPT_INSTALL` 记录。

修复：小型脚本下载保留 WebKit 当前响应，避免将同一带令牌/中转请求交给后台会话重新请求；安装识别支持服务端提供通用文件名，校验实际元数据，拒绝把 404、HTML 或普通 JavaScript 当作脚本；64 KiB 检测前缀即使截断了 UTF-8 字符也不丢失已完整读取的头部。

GitHub 仓库目前把可安装脚本放在 `build/` 下。旧的根目录 raw 链接返回 404，此处记录为过期发布链接，没有把它算作 Soulo 解析失败或安装通过。

## 网页与性能

- 无视频页面的 class/style 动画不再唤醒视频工具。本轮相同探针从 8 次定时唤醒、8 次布局帧降为 0/0。
- 同一 MutationObserver 批次中，新增父节点已覆盖其子树时不重复扫描：400 个子节点的探针从 401 次扫描降为 1 次。
- 视频工具的附近元素几何读取、懒创建、隐藏父容器、后续结果、移除和开放 Shadow DOM 回归通过；原生全屏进出及尺寸恢复回归通过。
- 保留 WebKit 的普通 HTTP 导航和原生返回。21 项浏览回归覆盖侧滑快照、等待中的子资源、首屏就绪、外观重复同步、标签/脚本复用、POST/重定向、返回同一文档、视频页返回、鉴权弹窗、重挂载及网络失败恢复等。
- 另发现网页按钮通过 JavaScript 跳转 magnet/ed2k/thunder 时会被静默忽略。现在接受同一文档、同一 WebView 的近期真实按钮/链接激活；无用户激活的脚本唤起仍被阻止，结果页面保持不变。隔离消息桥不能从网页伪造，专项原生测试通过。

性能数字来自专门的 DOM 工作量探针，不能视为整站提速比例。此次没有做与 Safari 的同条件真机加载/帧率对比。

## 系统暂停与恢复

`TorrentDownloadJob` 增加可选的系统暂停恢复标记，兼容旧账本。系统进入后台或保存检查点导致的暂停，在恢复前台时自动排队续传；进程中断时仍在执行的任务重开 App 后也可恢复。手动点暂停会清除标记，选文件界面不会被自动启动。恢复等待对应检查点保存完成，避免旧暂停覆盖新恢复。

iOS 回收后台执行时间后，恢复仍需要回到前台；不声称能绕过系统一直后台运行。在前台活动状态接收到后台任务到期回调时，不立即重新提交自身。相关自动恢复、手动暂停覆盖、重启进度及并发检查点用例通过。

## 指定磁力与边播边下

`065b4837e21de636289f83b7a99d10852feaa1c5` 已找到在线节点，包含三个 MP4 和两个填充文件。独立抓取有界头尾分片发现首个视频是 3840×2160、HEVC Main、hev1 标记、AAC，码率约 4.09 Mb/s；约 1.61 MB 的 moov 索引位于尾部。手机较早检查点尚未拥有这些索引分片。未下载完整影片，也未改动或删除手机任务文件。

修复：

- 播放前按实际媒体支持情况选择播放器，不再只凭 .mp4 后缀固定使用 AVPlayer；hev1 和原生不支持的媒体使用已有扩展解码器。普通 H.264 保留原生播放器。
- 原生检查支持取消，退出时取消尚未完成的媒体探测；需要扩展解码器时释放原生探测请求。
- 缺少分片的单次无进展等待上限从 60 秒增至 180 秒，允许较大的尾部索引在慢源上缓冲；关闭播放仍取消连接。
- 使用共享 VLC 库，避免每次播放器选项创建额外的解码库实例。
- 扩展解码器提前停止却不报告错误时，显示错误/重试状态，避免停在黑屏。

验证：

- 同类 HEVC/hev1＋AAC 测试素材从相同 HTTP 流接口播放，最终统计为 **103 个解码视频块、11 个已显示画面**，时间正常推进。素材由 testsrc2/sine 生成，未把用户视频加入仓库或安装包。
- 不完整的真实种子流通过产品 `MediaSession` 起播及 seek 后续播；普通 H.264 仍选择原生播放器。
- MKV 文件及流播放、拖动通过；仅已校验分片可读、范围请求、排除文件和路径边界通过。
- 无音轨 HEVC 样本在当前运行环境于 0.25 秒停止。该样本**没有获得播放成功证据**，本轮修复的是它的明确错误提示；不将其计入支持的播放组合。最初失败的结果包保留，没有通过降低播放推进断言把它记成可播放。

所有视频并非都能边播边下。能否起播还取决于容器、编码、索引位置、在线来源和可用分片；特别是高码率视频需要足够下载速度。上述同类样本验证不能冒充用户这条完整 4K 影片已经在真机连续播放。
