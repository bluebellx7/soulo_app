# 2026-11-12 用户反馈修复与影视入口检查

版本保持 **1.2.12**，最低 iOS **16.0**，未增加第三方依赖。保留工作区已有改动，本轮未提交、推送或部署。

## 已修复

- 主页照片和在线壁纸按 App 外观切换遮罩、底色和前景文字；浅色模式移除固定的黑色遮罩。
- BT/种子任务列表、详情显示进度条和百分比，暂停状态保留进度；原有续传与校验进度逻辑不变。
- 视频中央的加载动画与播放/暂停图标互斥，删除 Soulo 视频表面重复绘制的加载动画。
- iPad 跨域确认卡片最大宽度 520 点，按钮随卡片收窄；确认前保留源页面和地址，并暂缓发布脚本弹出的目标标签。
- 取消跳转不创建新标签、不发送目标页面请求；继续后沿用原 WebKit 窗口，保留 POST body 和 opener 关联。
- 为外部播放器尚未创建视频、或单一视频区域尺寸为零的情况提供原生播放入口；视频延迟出现和媒体就绪时重新检测。优先使用当前播放器配置；否则绑定具体视频元素。在没有明确播放器配置时，仅对唯一的非受保护视频提供备用入口，多个候选留给视频自身控件或资源面板选择。
- 资源识别覆盖开放的 Shadow DOM；空 `src` 不再误判为网页本身。接管同步读取已观察到的请求地址，播放器清空 Resource Timing 后仍可还原 blob 的媒体流。以查询参数标识影片/线路/分集的页面，选集排除其他影片的推荐链接。

- iPad 模拟器检查照片壁纸明暗效果、38% 下载进度和单一加载动画，并保留截图。

- 跨域跳转验证确认前没有目标 HTTP 请求、没有提前出现目标标签；取消、普通跳转和 POST 新窗口均回归。
- 媒体桥接和选集解析的 54 个定向用例中 53 个通过、1 个按设计跳过联网检查；联网检查单独执行，50 种语言与商店元数据检查通过。
- 前一批视频横向进度手势、实体音量反馈、平台网格长按排序、5 秒未启动提示和 iPad 预览的证据见 [验证记录](2026-11-12-video-gestures-and-ipad.json)。
