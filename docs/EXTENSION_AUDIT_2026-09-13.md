# 脚本扩展检查记录

## 检查结论

已按现有产品契约检查 UserScript 和原生 WebExtension。专项测试共 54 项通过，包含真实 WKWebView 中的脚本执行和原生扩展加载，不仅是字符串或编译检查。不能据此声称支持所有 Tampermonkey、Chrome 或 Firefox 扩展。

发现并修复原生扩展加载失败后仍显示开启的问题：启用时显示加载状态，失败恢复关闭并显示原因；启动恢复失败也反馈原因；处理异步加载期间停用、删除和列表变更。

## 逐项检查

| 项目 | 结果与实际边界 |
| --- | --- |
| 本地安装、编辑 | 文件导入与编辑共用大小、匹配规则和连接声明校验。空脚本/无效规则被拒绝，显式清空匹配范围不会扩大到所有网站。 |
| 重复安装/更新 | 来源 URL、更新/下载 URL 或名称+命名空间用于识别同一脚本；重新安装保留 ID、开关和存储。已补充更新后禁用状态与存储保留回归。 |
| 启停/卸载 | 停用后不再注入，删除后脚本存储写入被拒绝；内置示例不能误删。页面收到配置变更后重建运行时。 |
| 匹配与排除 | 验证 URL glob、匹配规则、排除路径、全 URL 规则；原生消息桥再次校验脚本 ID、令牌、开启状态和页面范围。 |
| 执行时机 | document-start、document-end；后者等待 DOMContentLoaded。当前 UserScript 仅注入主框架，不宣称完整 iframe 兼容。 |
| 权限 | 显式 @grant 限制 API，@grant none 关闭特权能力；未声明权限的旧脚本保留兼容行为。未支持权限在界面中提示。 |
| 脚本存储 | JSON 编码、单项 256 KB、脚本合计 1 MB、批量写入原子校验、更新保留、卸载后拒绝写入。 |
| DOM/API 运行 | 在 WKWebView 中验证 DOM、样式、元素创建、存储、URL API、内置阅读进度与区域文字提取示例。 |
| 菜单命令 | 注册、更新、清除和页面菜单入口已检查；命令按脚本归属管理。 |
| 特权网络 | @connect、当前主机限制、重定向复核、受限请求头、响应大小和超时限制已检查。普通 fetch 继续遵守 CORS。 |
| 资源依赖 | @resource API 是异步能力，需要相应 @connect；@require 只展示声明，不自动下载执行，产品文档已说明。 |
| 版本更新 | 支持手动重新安装更新；@updateURL/@downloadURL 是识别信息，没有后台自动更新服务。 |
| 隐私模式 | UserScript 不在隐私浏览中运行，文档已有说明。 |
| 原生扩展安装 | 本地 Manifest V3 安装、WebKit 加载、动作弹窗和兼容层实际测试通过。 |
| 原生权限 | 权限和网站访问请求经用户提示决定；不等同于所有跨商店权限/API 均可用。 |
| 原生接口 | 已核对当前 WebKit 主机接口覆盖；不支持的能力返回明确错误，已知可恢复资源警告不阻断整个扩展。 |
| 原生启用失败 | 新增测试：移除仅测试扩展的资源后重新启用，验证开关恢复关闭、错误可见、卸载清理错误状态。 |
