## 测试方法和局限

- 使用独立临时 XCTest UI 测试程序操作真实设备；测试项目位于 `/tmp/SouloPhysicalHarness`，不加入产品工程。
- 测试媒体为本地生成的三分钟 H.264/AAC 视频和提取的 M4A，没有访问用户媒体内容或密码库。
- 初次音频脚本用坐标点击未打开目标文件；改成元素原生 `tap()` 后同一流程通过。该次失败不归因为产品故障。
- 三个成功的测试结果包：`/tmp/soulo-physical-media1.xcresult`、`/tmp/soulo-physical-audio2.xcresult`、`/tmp/soulo-physical-airplay1.xcresult`。其中 AirPlay 的自动化成功仅代表脚本执行和输出选择，不代表接收端完整验收。
- 截图保留在上述结果包和 `/tmp/soulo-physical-*-shots`；系统设置截图可能包含账户显示名称，未复制进仓库。
- 两个测试文件暂留在 Soulo 文件页，便于手动继续验证：`Soulo-QA-20260916.mp4`、`Soulo-QA-Audio-20260916.m4a`。
