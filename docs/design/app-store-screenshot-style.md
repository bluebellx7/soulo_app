## 两类素材的视觉样式

| 素材 | 背景与配色 | 排版与设备构图 |
| --- | --- | --- |
| iPhone、iPad、Duo 截图 | 灰蓝渐变与大面积紫色块，黑色或白色文字 | 大字号无衬线字体，大幅真实设备边框；直立功能页与倾斜、跨张切片交替 |
| 标题、搜索结果素材 | 白底、黑色标题、浅金色标签与短横线、灰色辅助文字 | 左侧品牌及卖点，右侧三台手机叠放；中间首页手机直立在前，两侧手机向外倾斜 |

### 设备截图

- 紫色主色为 **`#6E54F1`**，从原图的平色色块读取。灰蓝背景是渐变，以原图为准；不是统一的单色填充。
- 灰蓝区域取样包括 `#9096A1`、`#87909E`、`#768398`，用于复现参考中的渐变层次，具体方向与分布按对应原图匹配。
- 紫色使用大幅弧形或斜切几何色块，在相邻图片间保持视觉衔接。部分页面可以紫色为主背景。
- 标题与说明使用无衬线字体。PNG 不能确认原始字体文件；有源设计文件时优先沿用源字体，没有时匹配参考中的字形、字重和行距。
- 灰蓝区域主要使用黑色文字，紫色区域可用白色标题。标题、`FEATURE` 标签和说明有明确大小差异，说明简短并围绕当前画面的功能。
- 功能页设备通常居中直立，占画面宽度约 80%–85%，真实 UI 需足够大、能看清。保留参考中黑色机身、金属边缘、侧键等设备细节。
- 展示页可以大幅倾斜、放大，设备延伸出画布；若使用跨张切片，需把相邻图片一起比对，维持设备位置和色块的连续性。推广标题与说明应完整可读。
- 同一组图片采用品牌介绍、跨张首页展示、具体功能页的节奏。功能内容根据新版本选择，维持参考的构图方式。
- 参考 UI 使用风景壁纸和较多深色界面。后续采集选择能呈现实际使用场景的真实 App 画面，设备外壳的屏幕比例与 UI 相符。

### 标题与搜索结果素材

- 纯白背景，大幅留白。
- 浅金色主色取样为 **`#DBB982`**，用于产品定位标签及短横线。
- 左上角为 App 图标与黑色 Soulo 品牌名。
- 左侧依次为浅金色产品定位、两行黑色粗体大标题、浅金短横线与灰色功能说明；左下保留小号灰色品牌口号。
- 右侧三台黑色手机叠放，中间首页在最前方，两侧展示资源检查和平台管理；保持明显的前后关系与自然倾斜角度。
- 主标题使用粗体无衬线字体，中文和英文分别调整字号与断行，保持相同视觉重量。
