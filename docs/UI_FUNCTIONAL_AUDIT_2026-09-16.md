# Soulo UI、功能与扩展回归（2026-09-16）

工程版本保持 1.1.6 (24)。本批修改未提交、未推送；保留工作区既有修改。

## 已完成

- 网页工具中广告过滤固定置顶；首页、标签菜单、媒体倍速使用中性色图标，删除/关闭操作保留红色；桌面模式使用空心显示器。
- 锁面板保护开关为单行，详情入口灰色；标记广告与隐私设置同排并显示标记数量。浅色卡片增加半透明灰底与细边线，便于区分各组。
- 已标记广告列表增加网站分组、统计、搜索、作用范围、路径、选择器、日期、详情页、恢复与撤销；遵循广告过滤开关和网站白名单。
- 顶部标签栏开关放进标签页省略号弹窗，附两种布局示意；设置持久化，单标签不显示顶部栏。
- 阅读模式作为扩展中心末尾的内置开关，启用后通过网页脚本命令使用；禁用后移除命令入口。
- 下载完成提示可跳转下载列表；剪贴板提示显示截断摘要，实际搜索使用完整内容。读取剪贴板改为异步，避免主线程等待系统粘贴授权。
- 扫描取景框只绘制四个圆角；隐私设置“移除跟踪参数”改为有效的 `link` 符号。
- 反馈提交附带可预览、可关闭的设备/App/设置诊断信息及用户主动填写的联系方式。不会采集个人设备名称、唯一标识、浏览记录、网页内容或剪贴板。保留原接口及请求字段，空内容/超长内容不能提交，失败保留输入。
- 本地媒体切换后 0.5× 启播偶发停滞：统一等待 AVPlayer 解码准备后按默认速率播放，保留原有倍速与拖动功能。
- 锁面板连接信息右侧增加网页二维码入口。本地生成完整网址、高纠错二维码，中心嵌入可获取的网站 favicon；图标获取失败时保留可用二维码。支持复制完整二维码图片（包含网站图标）、带缩略图/标题的系统分享和仅添加相册权限的保存，明确显示保存结果；拒绝相册权限时在页内说明，支持重试。
- 二维码页底部使用保存/复制图片/分享三个操作；复制完成显示两秒“已复制”，之后可再次复制。增加与既有插画一致的透明手绘插画，位于标题上方。导入图片约 196 KB，浅色/深色共用现有插画组件；生成方式与完整提示词见 `qa/page-qr-illustration.md`。

## 覆盖边界与排查记录

- 359 项回归覆盖浏览与标签状态、下载与音频、文件与阅读、隐私/广告策略、用户脚本和原生扩展 API、布局/语言及已有性能回归；不能替代所有第三方网站、脚本与设备组合的实测。
- 用户脚本仍遵循现有权限与匹配规则；外部 `@require` 不自动执行，隐私标签不运行用户脚本；原生扩展支持范围见 `EXTENSION_AUDIT_2026-09-13.md`，不承诺完整 Chrome/Tampermonkey 兼容。
- 反馈服务采用模拟 HTTP 成功/失败响应验证，没有向正式接口提交测试反馈。
- 摄像头连续识别、真实触感及 AirPlay 需要真机验证。模拟器验证图片二维码解码；取景框调整不改动识别流程。
- 曾在全量测试中复现本地音频 0.5× 停滞，单独修改测试 seek 精度没有解决；生产播放逻辑调整后全量通过。
- XCTest 个别流程等待动画完成通知超过一分钟；采样显示 App 主线程在正常 run loop。临时 UI 宿主对相关用例采用显式元素等待，绕过其内部静默等待；生产 App 未引入该自动化适配。
- 测试日志仍有 WebKit/模拟器系统诊断及既有 SwiftUI 更新阶段警告；未把“通过回归”表述为所有环境零错误。后续若出现对应可见异常，应保留现场继续定位。

可复用 UI 测试源码及本地网页见 `docs/qa/`，在独立测试宿主运行，不打包进生产 App。二维码 UI 测试的本地服务器应提供 `/index.html` 及 `/favicon.ico`。

二维码交互验证初期的失败来自测试脚本将系统“关闭”写成英文，以及模糊匹配“允许”误选“不允许”；均已修正测试定位，最终授权/拒绝分开验证通过。拒绝权限后的提示改为页内展示，避免依赖系统授权弹窗消失时的二次弹窗。

复制测试中 App 在点击后即显示“已复制”；独立 QA Runner 读取另一个 App 写入的系统剪贴板时，iOS 授权机制等待约两分钟，随后读到图片且解码校验通过。该耗时发生在测试读取端，生产复制操作不读取剪贴板。
