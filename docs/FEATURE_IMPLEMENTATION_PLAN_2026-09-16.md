# 无页面布局变更的功能补齐

保留现有页面布局，通过系统交互、现有菜单和阅读外观设置补齐能力。版本保持 1.1.6 (24)。

- [x] 播放中断恢复、画中画 / AirPlay 状态回归
- [x] 系统密码自动填充兼容检查
- [x] 文件跨 App 拖入 / 拖出
- [x] Handoff（排除隐私模式和本地地址）
- [x] 长按视频临时倍速，松手 / 取消恢复
- [x] 文本编码识别与明确指定编码
- [x] 视频截图、镜像（现有播放器菜单）
- [x] 文件“文本打开”和编码菜单
- [x] 系统相册导入（现有导入菜单）
- [x] TXT / EPUB 简繁显示转换，保留源文件
- [x] 定向测试、编译、本地化检查、更新能力审计

真机验证项单列：跨 App 画中画、AirPlay 外设、第三方密码管理器账户、跨设备 Handoff、iPad 跨 App 拖拽。模拟器或源码检查不能替代这些验证。


## 实现边界

- 没有新增主页面或常驻功能条；新增入口位于原有导入、文件长按、播放器菜单和阅读外观内。
- 镜像仅改变 App 画面与截图；系统 PiP / 外部 AirPlay 保留系统媒体渲染行为。
- 相册和拖拽导入复制文件，原文件不移动、不删除；不支持拖入目录或符号链接。
- 简繁转换按当前加载章节分批进行，默认原文不扫描正文；保留原节点字符串，切回原文不反向猜测转换。
- 不扩展 DRM / KFX / DLNA 支持；RAR 创建、通用编辑器、Cookie 管理等仍保持审计中的未支持状态。
- 新增工具文案沿用 ReadingTools 三语言表和英文后备机制，未修改 App Store 版本或商店文案。


## 定向验证记录

- `IncrementalFeatureTests`：Handoff 私有/本地地址排除、BOM/指定编码、中文显示转换、导入临时文件生命周期与重名、视频临时倍速/中断恢复/截图。
- `ReadingToolsTests`：25 项原有阅读、媒体、Wi-Fi 与压缩测试通过；另扩展 EPUB 测试，检查中文正文转换及代码块不变。
- 简繁转换使用真实 `BookWebSurface` + WKWebView；初次测试窗口缺少 UIWindowScene，补齐测试宿主后通过，没有放宽断言。
- `check_localization.py --strict` 与 `export_metadata_json.py --check` 通过（862 keys × 50 locales / 50 份商店文案）。

- 界面链路已验证：相册实际导入（含同名副本）、文件长按文本打开、菜单切换 Windows-1252 正确显示 café、视频镜像、全屏返回、提帧后系统分享面板。
- 回看截图发现主播放页与临时小窗可能争用 AVPlayerLayer；已增加主播放面优先级和对应生命周期测试，首次进入、镜像及全屏返回的实际画面像素均已验证通过。
